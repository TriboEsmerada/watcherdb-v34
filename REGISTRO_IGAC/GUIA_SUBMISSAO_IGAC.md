**Descrição Resumida (250-500 palavras):**

```
WatcherDB é uma plataforma avançada de monitoramento, diagnóstico e gestão
proativa de infraestrutura de bases de dados SQL Server e Oracle, desenvolvida
para ambientes corporativos de missão crítica.

O software foi desenvolvido internamente pela TAP - Transportes Aéreos
Portugueses entre 2024 e 2025, utilizando tecnologias modernas como Python 3.13,
FastAPI, e algoritmos de Machine Learning (ARIMA, Holt-Winters) para análise
preditiva.

Principais funcionalidades:
- Monitoramento em tempo real de KPIs críticos (CPU, memória, espaço)
- Análise preditiva com Machine Learning para prever crescimento de bases de dados
- SQL Diagnostics com 15+ queries especializadas
- Detecção de Disk Overflow e alertas proativos
- Interface web responsiva com visualizações interativas
- Suporte a múltiplos servidores SQL Server e Oracle

O WatcherDB representa ~20.000 linhas de código original, desenvolvidas
especificamente para as necessidades da TAP, combinando tecnologias open-source
com lógica proprietária e algoritmos internos.

Tecnologias utilizadas: Python, FastAPI, JavaScript, HTML5, CSS3, statsmodels,
scikit-learn, pandas, pyodbc, cx_Oracle.
```
